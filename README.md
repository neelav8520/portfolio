# Neela V — Ultra-Animated Portfolio

Built from the supplied black/lavender reference and the detailed portfolio brief.

## Stack
Next.js 14, React, TypeScript, Tailwind CSS, GSAP, Framer Motion, Lucide React.

## Routes
- `/` homepage
- `/work/social-media`
- `/work/seo`
- `/work/meta-ads`
- `/work/creatives`

## Update your work
Edit `data/projects.ts`. Each project supports title, category, image, description, client, services, year and results. Replace the SVGs in `public/images` with your real screenshots/creatives.

## Personal details
Replace the email, phone, LinkedIn and Instagram placeholders in `app/page.tsx`. Add `public/resume.pdf`.

## Run
`npm install` then `npm run dev`.
